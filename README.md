SIGN/e • SYMBOL-BASED INTERFACE FOR GRAPHIC NOTATION/EDITION
Visual editing plugin (AMXD) to read & write graphic scores directly in Ableton Live. Import, modify, and animate PNGs images as instructions for live performers. SIGN/e lets you push beyond the limitations of conventional notation software to create scores that bridges the gap between your Ableton Live session and live performance.

Programmed by Evan Montpellier for Laboratoire formes • ondes at the Digital Music Dept. of Université de Montréal.
